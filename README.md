# 📊 HealthConnect Analytics — Week 5

## 📌 Project Overview

**HealthConnect Analytics** is a healthcare appointment data analysis project completed as part of my **AnalystLab Africa** learning journey.

The project uses appointment data to explore attendance patterns, no-shows, reminder effectiveness, and other factors that may influence appointment outcomes.

## 🎯 Project Objectives

- Clean and prepare the appointment dataset for analysis
- Explore appointment attendance and no-show patterns
- Analyse the relationship between reminders and appointment outcomes
- Examine booking lead time, waiting time, and distance to the clinic
- Identify meaningful patterns and insights
- Present findings through an interactive dashboard and analytical report

## 🛠️ Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**
- **Power BI**

## 🔍 Analysis Areas

The analysis focuses on:

- Appointment outcomes
- No-show patterns
- Reminder status and channels
- Previous appointments
- Previous no-shows
- Booking lead time
- Waiting time
- Distance to the clinic
- Data quality and missing values

## 💡 Key Insights

The analysis explores factors associated with appointment attendance and no-show behaviour, including previous appointment history, reminders, booking lead time, waiting time, and distance to the clinic.

The findings provide insights that can help improve appointment management and patient engagement.
